# Upstream material and provenance

The implementation in this repository is the reproducible **new assignment**.
The supplied source material is referenced, but large binary files and
publisher-protected papers are deliberately not duplicated in the public Git
history.

## Assignment 1

The original PC-FMCW/DPSK notebook and technical report remain available in
the authors' Assignment-1 repository:

- [PanagiotaGr/ISCAI_pc_fmcw](https://github.com/PanagiotaGr/ISCAI_pc_fmcw)

`docs/ASSIGNMENT1_MAPPING.md` documents exactly how the previous waveform,
sensing and communication work is carried into the predictive scheduler.

## Reference paper

S. Liu, T. Sun, X. Shu, J. Song and Y. Dong, “Phase-coded FMCW Laser Headlamp
for Integrated Sensing, Communication, and Illumination,” *IEEE Photonics
Technology Letters* (2025), DOI:
[10.1109/LPT.2025.3649597](https://doi.org/10.1109/LPT.2025.3649597).

## Planning documents

The three supplied planning PDFs were used to define the research questions,
causal protocol, baselines, ablations and communication-aware objective.
Their implementable specification has been consolidated into:

- `docs/METHODOLOGY.md`
- `docs/EXPERIMENTS.md`
- `docs/DATA_PROVENANCE.md`
- `docs/RESULTS.md`

This policy keeps the repository lightweight, reproducible and safe to publish.
